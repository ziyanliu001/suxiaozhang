# 平台商业化战略与盈利模型体系

## 核心战略定位（公益树品牌，商业做变现）

- **公益专区**（雨花斋 / 助老食堂 / 救灾服务等）：坚持**完全免费、公开透明、全社会监督**。作为平台的公信力基石与品牌护城河，实现零成本获客并沉淀极高社会信任度。任何"查看"类的公益数据展示，默认不得挂订阅套餐门槛（参见 `CLAUDE.md` 中「多租户隔离与全国公信力大屏双轨制设计」一节记录的历史教训）。
- **商业专区**（商业素食门店 / 直播产销工坊 / 品牌连锁）：作为**核心盈利引擎**，提供深度数字化生产力工具、供应链赋能与高阶资产化变现。收费点应落在"深度功能 / 规模化管理 / 数据资产化"上，而不是基础可见性上。
- **⚠️（2026-09-05 战略扩展）雨花公益专区扶持例外**：第一阶段支柱 1 里的"税局/审计级 Excel 导出包"原则上仍是收费项，但**雨花斋门店（`orgType === 'yuhuazhai'`）导出财务审计表本身免拦截**，作为对公益扶持业态的专项让利——这是对上面"公益专区完全免费"原则的一次**扩展**（从"仅限查看类展示"扩展到"审计导出这一项深度功能"），不是对该原则的推翻，且严格限定在"导出审计表"这一个功能点，不代表雨花斋门店在"多店合并导出"「进销存」等其余商业专区功能上同样免费。通用素食等其余业态（`orgType !== 'yuhuazhai'`）继续按原规则收费，凭兑换码/在线购买升级专业版后方可导出。代码落点：`pages/statistics/statistics.ts` 的 `exportToExcel()`/`resolveIsYuhuazhaiStore()`。个人中心「专业版服务状态/立即开通」这两张推销卡片对雨花斋账号也彻底隐藏（`profile.wxml`，`!isYuhuazhai` + `isOrgTypeResolved` 双重门槛，避免 orgType 尚未查证完毕时先闪一次卡片）。
- **⚠️（2026-09-05 战略扩展·续）雨花公益专区门店数量配额豁免**：支柱 1 里"多门店连锁管理需付费"这条对雨花斋门店同样开例外——**新建雨花斋门店（`orgType === 'yuhuazhai'`）完全不占用、也不检查机构的门店数量配额**（`tenants.currentStoreCount` 现在的语义收窄为"仅统计非雨花斋门店"），商业门店满 2 家（基础版）仍需升级/购买扩容包的规则不变。代码落点：`cloudfunctions/createStore`、`cloudfunctions/processRoleAudit`、`cloudfunctions/manageTenantSubscription`（`assignStoreToTenant`/`removeStoreFromTenant`）里各自的配额占用/归还逻辑，均已按 `orgType` 分流。
  - **已知遗留风险，如实记录**：`orgType` 是门店级字段，由超管在建店/编辑门店档案时自行填写，**未经任何资质核验**——理论上任何人都可以把商业门店标成 `yuhuazhai` 来绕开门店数量配额，这是本次扩展主动接受的一个信任假设（依赖超管诚信自律），不是技术上无法绕过的硬边界，后续如需收紧需要引入雨花斋资质审核机制。
  - **已知数据口径缺口**：本次改动只影响"从今往后新建/迁移的门店"如何计数，**存量已经计入 `currentStoreCount` 的历史雨花斋门店不会自动扣减**，会让个别老机构的"已用门店数"展示值偏高于真实商业门店数，需要时走人工核对/一次性校正脚本，本次未做批量数据迁移。

## 第一阶段：五大基础盈利支柱（稳健现金流与规模化底座）

1. **SaaS 订阅与多租户增值服务**
   - 商业门店 / 连锁版：进销存、收银台账、会员管理、多门店财务合并报表（年费订阅）。
   - 直播产销工坊版：排单生产、批次追溯、直播带货履约与供应链分账系统。
   - 功能增值包：税局/审计级 Excel 导出包、多角色权限协同包、自动化短信/模板消息包。
   - 代码落点参考：`miniprogram/utils/tenantPermission.ts` 的 `FEATURE_KEYS`（`MULTI_STORE_DASHBOARD`/`EXCEL_EXPORT`）与 `tenant_subscriptions` 集合。

2. **供应链集采对接与交易分佣**
   - 汇聚全国公益食堂与商业门店的采购需求，直连米面粮油、环保餐盒、消杀物资源头工厂，赚取集采差价与供应商返点（1%～5%）。
   - 产销工坊特色素食产品/预制菜的多渠道分销代销分成（Take Rate）。

3. **支付通道与金融增值服务**
   - 作为微信支付/银联服务商，获取商业交易流水费率分成。
   - 基于商户授权的真实经营数据，联合持牌金融机构提供小微周转贷撮合佣金。

4. **机构定制与私有化实施**
   - 为大型慈善基金会、知名连锁素食品牌提供私有化部署、专属域名、定制数据驾驶舱与品牌小程序。
   - 硬件（智能称重、客流监控）与三方 ERP（金蝶、用友）系统集成实施费与年度维保费。

5. **政策补贴与社会影响力资本（ESG 资金）**
   - 依托数字化透明助老与社会救助账目，申报民政/科技部门数字养老等政府采购与公共服务补贴。
   - 申请科技向善（Tech for Good）与 ESG 影响力投资资助。

## 第二阶段：四大高阶生态升维模式（高壁垒与资产化变现）

1. **ESG 碳积分与绿色普惠金融**
   - 将素食餐次、低碳饮食、志愿服务转化为标准碳减排数据，向大中型企业/上市公司销售「企业 ESG 员工餐/CSR 减碳解决方案」。
   - 依托透明进销存与真实履约链条，联合银行提供小微「善粮贷」等绿色供应链金融利差分成。

2. **D2C 品牌孵化与「善意严选」自营生态**
   - 从纯软件工具升维为供应链渠道品牌，联合优质直播产销工坊反向定制高毛利自营/联名爆品（素斋预制菜、健康零食），获取 30%~50% 实物高毛利。

3. **数字素食学院与轻托管代运营（FaaS）**
   - 输出主厨培训、店长认证与运营 SOP 知识付费课程。
   - 为社会资本与爱心基金会提供「建店+系统+供应链+托管」交钥匙整包方案，收取实施费与流水管理费。

4. **「时间银行」积分联盟与企业 EAP**
   - 义工工时积分与外部绿色品牌（健康体检、出行、有机超市）跨界互通，获取导流佣金与品牌营销费。
   - 向企业销售员工志愿服务与心理关怀包（EAP），输出企业社会责任与文化建设报告。
